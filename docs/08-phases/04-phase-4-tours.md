# Phase 4 — Tours and Departures

**Goal:** a tour catalogue with real departures and safe inventory administration. Specs: `05-features/03-tours-catalog.md`, `04-api/04-tours-departures.md`.

## Tasks

### Backend
1. Models: `Tour`, `TourDeparture` with indexes.
2. Tours service: list (filters, month, price range, sort, `fromPrice`, `nextDeparture` via aggregation), detail with departures and temples, slug redirects.
3. Departures service: create, update (date-change guard), inventory adjust (atomic delta with committed-seat guard; committed = 0 until Phase 5 but the guard queries bookings collection), cancel (booking transitions stubbed until Phase 5, tested then), delete rules, `isBookable` computation, `full` ↔ `scheduled` helper.
4. Admin tours CRUD, publish prerequisites, archive guard, images.
5. Temple detail now includes "tours covering this temple"; circuit detail includes tours.
6. `complete-departures` job (hourly).
7. `seed-sample-tours.js` (refuses in production).
8. Tests: fromPrice and nextDeparture correctness, month filter, publish rules, inventory adjust (including concurrent adjustments), archive guard, completion job.

### Frontend
9. `/tours` list with filters and sort.
10. `/tours/[slug]` detail with itinerary, inclusions, temples, departures table, sticky booking card / mobile bar (CTA goes to login or a "Booking opens in Phase 5" stub behind a flag).
11. Home: enable upcoming tours section.
12. Temple and circuit pages: tours sections.
13. Admin tours list, tabbed form, itinerary editor (rows auto-generated by duration), temple multi-select, FAQs, SEO.
14. Admin departures tab: table, add/edit dialog, inventory dialog, cancel dialog, bulk add (Should).
15. Sitemap includes tours; `TouristTrip` + `FAQPage` JSON-LD.

## Exit criteria

Status on 2026-10-20 (details in `10-testing/reports/phase-4.md`):

- [x] Admin creates a tour with itinerary and two departures and publishes it; it appears in list, detail, temple pages and sitemap.
- [x] Inventory reduction below committed seats is refused (test with seeded bookings fixture).
- [x] Departure within cutoff shows "Booking closed".
- [ ] Lighthouse and axe targets met on tour detail. (axe clean, Accessibility 100; Performance 57–59 and SEO 92 locally, same causes as Phase 3.)
- [x] All Phase 4 tests green.
